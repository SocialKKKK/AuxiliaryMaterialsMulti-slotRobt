# 0.2 Version Requirements

本目录用于承接 0.1 之后、final 之前的增量需求。

## Scope Rule

0.2 只记录下一阶段明确要实现和验收的内容。还没有确定进入 0.2 的能力，先保留在 `../final/` 或 `../../baseline/`，不要提前复制到这里。

- [需求范围.md](需求范围.md)：0.2 版本功能范围。

- [变更说明.md](变更说明.md)：相对 0.1 的新增、调整和删除项。
- [物料存取记录-需求确认清单.md](物料存取记录-需求确认清单.md)：需求方逐项确认原文、5 条决议与实现清单。
