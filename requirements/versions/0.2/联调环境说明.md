## 5. 部署与回滚

**部署**（原地覆盖，不新建目录）：

1. 停 HMI（单一实例）。
2. 覆盖 `...\bin\Release\net8.0-windows\` 的 Release 产物。
3. **同步 `requirements\data-access-sql\sql-catalog\items\`**（漏推会因为「缺少 SQL 条目」静默降级 → 记录缺门时刻）。
4. `station-config/stations.yaml` 如需变更单独同步；`appsettings.Local.json`、`io-modules.yaml`、`data/` **必须保留**。
5. 启动 → 核对连接（状态栏 `MES✓`、`IO 4/4`、`RCS`）、schema、记录页。

库**不用手工动**：启动时 `OperationLogSchema.Ensure` 幂等补列、建触发器、开 WAL。

**回滚**：只换 DLL 即可（新增列对旧代码是可空且被忽略的；触发器只拦 UPDATE，旧代码从不 UPDATE 记录表）。现场回滚物见 `verification/2026-10-09/` 与柜体机 `C:\autotest\`。

## 6. 现场操作注意事项（踩过的坑）

1. **取库副本必须 db + wal + shm 一起取**。只拷 `app.db`（不带 WAL）会**静默少读**尚未 checkpoint 的记录——本次现场实测差 5 条，看着像"丢记录"。备份同理（见 [运维说明-归档与备份](运维说明-归档与备份.md) §3）。
2. **`dbcheck.py pairs` 必须带 `--since`**，否则会把口径优化前 854 条历史「无来源关门」报成不一致。
3. **导出/查看留痕**写在记录表里（`export_operation_log` / `view_operation_log`），可用来判断"有没有人导出过"。
4. 记录页门禁：维护 `S0020310`、物料员 `1`（值以 Local 为准）。
